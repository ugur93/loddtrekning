# Loddtrekning

Static single-page loddtrekning. Tickets stay in the browser (`localStorage`). No server.

GitHub repo: https://github.com/ugur93/loddtrekning
Live: https://ugur93.github.io/loddtrekning/

The GitHub Action builds the app and publishes the `gh-pages` branch.

## Local

```sh
npm install
npm run build:pages
```

Output is `dist-pages/`.
